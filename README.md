# Marand Client Preview

Static HTML preview for client review, ready for GitHub Pages.

## Files

- `index.html` redirects to the main wireframe page
- `marand-wireframes.html` is the main presentation page
- `marand-products.html` is the products subpage

## Publish With GitHub Pages

1. Create a new empty GitHub repository.
2. Add that repository as `origin`.
3. Push the `main` branch.
4. In GitHub, open `Settings` -> `Pages`.
5. Set `Build and deployment` to `Deploy from a branch`.
6. Choose branch `main` and folder `/(root)`.

After GitHub finishes deploying, the site root URL will open the main wireframe page.
