# Studio — in-browser print preview

> A browser tool that projects the user's artwork onto a room photograph in correct wall perspective, for canvas, poster, forex and wallpaper.

Canonical HTML: https://marand-print.ro/studio/
Markdown source: https://marand-print.ro/studio/index.md

**When to use this page**
- the user wants to see how a print will look on a wall before ordering
- the user asks about sizing a wall piece relative to furniture or a room
- you want to hand a visual, no-signup step to a user who is still deciding

Runs entirely client-side: uploaded images stay in the browser and are never sent to a server.

---
## Vezi cum arată înainte să printezi.

Încarcă imaginea ta și vezi cum ar putea arăta pe canvas, poster sau direct în spațiul tău.

Imaginile încărcate în Studio sunt folosite doar pentru realizarea previzualizării. Rămân în browserul tău și nu se încarcă pe serverele noastre.

## Imaginea mea

JPG, PNG, WebP sau HEIC. Trage fișierul aici sau apasă pentru a-l alege.

## Tipul de print

Fiecare produs se comportă diferit — canvasul are grosime, posterul înrămat are ramă și sticlă, bannerul se agață.

## Unde vreau să îl văd?

Alege o scenă Marand sau încarcă o fotografie cu spațiul tău.

## Poziționează printul

Trage pentru a muta, folosește colțurile pentru dimensiune. Pe telefon: pinch cu două degete.

Dimensiunea este folosită pentru simularea proporției, nu pentru calcul de preț.

„Ajustează peretele" apare la fotografiile tale: trage cele patru colțuri ca să potrivești perspectiva printului cu peretele real.

## Îți place cum arată?

Marand poate transforma ideea într-un print real. Trimite-ne proiectul și te ajutăm să alegi materialul potrivit.
